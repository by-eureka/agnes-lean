# AGNES in Lean 4

This Lean formalization was generated by **by-eureka** using DeepSeek Flash and Leanbeam. It accompanies *Nesterov acceleration despite very noisy gradients* by Kanan Gupta, Jonathan W. Siegel, and Stephan Wojtowytsch. [by-eureka harness](https://github.com/by-eureka/eureka) · [Paper on arXiv (v3)](https://arxiv.org/abs/2302.05515v3)

## Proof status

The six modules contain Lean statements corresponding to all nine numbered theorems in the paper. Of 70 theorem and lemma declarations, including helpers, 54 use only Lean’s standard axioms and 16 depend on `sorry`.

- **Theorem 17.** `AGNES.gd_convex` proves the general stochastic gradient-descent bound for an arbitrary comparison point. The sharper specialization at a minimizer remains open. [Lean source](Proofs/Part3.lean#L360)
- **Theorem 22.** `AGNES.gd_pl_convergence` proves the geometric rate for the expected objective value. The almost-sure and mean-square convergence of the iterates remains open. [Lean source](Proofs/Part3.lean#L413)
- The main AGNES acceleration rates remain open. The statements for Theorem 4 record the parameter choices used in the formalization. [Convex rates](Proofs/Part4.lean) · [Strongly convex rates](Proofs/Part5.lean)

The stochastic model assumes a probability measure and integrated identities for the gradient oracle. Deriving those identities from the paper’s independently sampled, pointwise oracle remains an open step. [Stochastic model](Proofs/Part2.lean)

## Build

With Git and Elan installed, run these commands from the repository root. The project pins Lean 4.35.0 and the Mathlib revision.

```bash
lake exe cache get
lake build
```

Lean accepts unfinished proofs with a warning. To check a particular declaration’s dependencies, run the following from the same directory. An unfinished dependency appears as `sorryAx`.

```bash
lake env lean --stdin <<'LEAN'
import Proofs
#print axioms AGNES.gd_convex
#print axioms AGNES.gd_convex_min
LEAN
```
